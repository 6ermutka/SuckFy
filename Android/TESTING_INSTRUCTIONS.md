# 🧪 Инструкция по тестированию фонового воспроизведения

## Установка обновлённого приложения

### Вариант 1: Через Metro (рекомендуется для тестирования)
```bash
# В одном терминале запустите Metro
npx react-native start

# В другом терминале установите на устройство
npx react-native run-android
```

### Вариант 2: Установка готового APK
1. Скопируйте `android/app/build/outputs/apk/debug/app-debug.apk` на устройство
2. Откройте файл на устройстве
3. Разрешите установку из неизвестных источников (если требуется)
4. Нажмите "Установить"

## Тестовые сценарии

### ✅ Тест 1: Базовое фоновое воспроизведение

1. **Подготовка:**
   - Загрузите минимум 3 трека в приложение
   - Убедитесь, что треки скачаны (есть filePath)

2. **Действия:**
   - Запустите воспроизведение первого трека
   - Подождите 10-15 секунд
   - Сверните приложение (кнопка Home)
   - Подождите, пока текущий трек закончится

3. **Ожидаемый результат:**
   - ✅ Следующий трек должен начать играть автоматически
   - ✅ Уведомление должно обновиться с новым названием трека
   - ✅ Можно управлять через уведомление (пауза/play/next/prev)

### ✅ Тест 2: Воспроизведение при заблокированном экране

1. **Действия:**
   - Запустите воспроизведение плейлиста
   - Заблокируйте экран кнопкой питания
   - Подождите окончания трека

2. **Ожидаемый результат:**
   - ✅ Следующий трек начнёт играть
   - ✅ На экране блокировки видны элементы управления
   - ✅ Информация о треке обновляется

### ✅ Тест 3: Режим повтора (Repeat)

1. **Действия:**
   - Включите режим Repeat
   - Запустите один трек
   - Сверните приложение
   - Подождите окончания трека

2. **Ожидаемый результат:**
   - ✅ Тот же трек начнёт играть снова
   - ✅ Повтор работает в фоновом режиме

### ✅ Тест 4: Управление через уведомление

1. **Действия:**
   - Запустите воспроизведение
   - Сверните приложение
   - Используйте кнопки в уведомлении:
     - Pause/Play
     - Next
     - Previous

2. **Ожидаемый результат:**
   - ✅ Все кнопки работают корректно
   - ✅ Состояние синхронизируется с приложением

## Проверка логов

Если что-то не работает, проверьте логи:

```bash
# Фильтр по тегам приложения
adb logcat | grep -E "PLAYER|AUDIO|NOTIFICATION"
```

### Ожидаемые логи при успешном переключении:

```
🎵 [PLAYER] Attempting to play track: Track Name
🎵 [AUDIO PLAYER] Loading track: /path/to/file.mp3
🎵 [AUDIO PLAYER] Track completed event received
🎵 [PLAYER] handleTrackCompletion called
🔁 [PLAYER] Repeat: false | Index: 0 | Queue length: 3
⏭️ [PLAYER] Auto-advancing to next track: Next Track Name | Index: 1
✅ [PLAYER] Playback started successfully
```

## Известные особенности

1. **Wake Lock ограничен 10 минутами** - для треков дольше 10 минут может потребоваться дополнительная настройка
2. **Первый запуск после установки** - может потребоваться перезапуск приложения
3. **Android 13+** - требуется разрешение на уведомления

## Возможные проблемы и решения

### Проблема: Треки не переключаются в фоне

**Решение:**
1. Проверьте, что треки загружены (есть filePath)
2. Перезапустите приложение
3. Проверьте логи на наличие события `onTrackCompleted`

### Проблема: Нет уведомления

**Решение:**
1. Проверьте разрешения приложения в настройках Android
2. Разрешите уведомления для SuckFy
3. Перезапустите приложение

### Проблема: Приложение тормозит в фоне

**Решение:**
1. Отключите оптимизацию батареи для SuckFy
2. Настройки → Батарея → Оптимизация → SuckFy → Не оптимизировать

## Успешный тест

Тест считается успешным, если:
- ✅ Треки автоматически переключаются в фоне
- ✅ Уведомление обновляется при смене треков
- ✅ Управление через уведомление работает
- ✅ Режим повтора работает корректно
- ✅ Нет крашей и зависаний
