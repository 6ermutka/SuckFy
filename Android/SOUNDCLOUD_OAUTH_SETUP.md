# Как получить OAuth токен для SoundCloud

## Метод 1: Через браузер (самый простой)

1. **Откройте SoundCloud в браузере** и авторизуйтесь
2. **Откройте Developer Tools** (F12 или Cmd+Option+I)
3. **Перейдите во вкладку Console**
4. **Вставьте и выполните этот код:**

```javascript
// Получить OAuth токен из localStorage
const token = Object.keys(localStorage)
  .filter(key => key.includes('oauth'))
  .map(key => localStorage[key])
  .find(val => val && val.includes('oauth_token'));

if (token) {
  const parsed = JSON.parse(token);
  console.log('OAuth Token:', parsed.oauth_token);
  // Скопируйте токен в буфер обмена
  copy(parsed.oauth_token);
  console.log('✅ Токен скопирован в буфер обмена!');
} else {
  console.log('❌ OAuth токен не найден. Убедитесь что вы авторизованы.');
}
```

5. **Скопируйте токен** из консоли или из буфера обмена
6. **Вставьте в приложение** в Settings → SoundCloud OAuth

## Метод 2: Через Network инспектор

1. **Откройте SoundCloud в браузере** и авторизуйтесь
2. **Откройте Developer Tools** → вкладка **Network**
3. **Включите фильтр XHR/Fetch**
4. **Обновите страницу** или выполните любое действие (например, поиск)
5. **Найдите любой запрос к api-v2.soundcloud.com**
6. **Посмотрите в Headers** → Request Headers → **Authorization**
7. **Скопируйте значение** после "OAuth " (без "OAuth ")

Пример:
```
Authorization: OAuth 2-294731-123456789-AbCdEfGhIjK
```
Ваш токен: `2-294731-123456789-AbCdEfGhIjK`

## Метод 3: Через Application Storage

1. **Откройте SoundCloud** и авторизуйтесь
2. **Developer Tools** → вкладка **Application** (или Storage)
3. **Local Storage** → `https://soundcloud.com`
4. **Найдите ключ** содержащий "oauth" или "session"
5. **Скопируйте значение** oauth_token

## Проверка токена

После получения токена, вставьте его в приложение:
1. Откройте **Settings** в приложении
2. Секция **SoundCloud OAuth**
3. Вставьте токен в поле
4. Нажмите **Сохранить токен**
5. Приложение автоматически валидирует токен
6. Если токен валиден - увидите **✅ Токен активен**

## Важно

- OAuth токен **привязан к вашему аккаунту** SoundCloud
- Токен дает доступ к **вашим плейлистам, лайкам** и другим приватным данным
- **Не делитесь** токеном с другими людьми
- Токен может **истечь** - в этом случае получите новый
- Приложение **работает и без токена**, используя публичные client_id, но с ограничениями

## Преимущества OAuth токена

✅ Доступ к приватным трекам и плейлистам
✅ Более высокие лимиты API
✅ Доступ к Go+ контенту (если у вас подписка)
✅ Меньше ошибок 429 (rate limiting)

## Работа без токена

Если не хотите вводить OAuth токен - приложение работает в режиме public API:
- Используются публичные client_id
- Доступны только публичные треки
- Могут быть лимиты на количество запросов
- Автоматическое переключение между несколькими client_id при ошибках

## Troubleshooting

### Токен не валидируется
- Убедитесь что скопировали **весь токен** целиком
- Проверьте что нет пробелов в начале/конце
- Токен начинается с цифры (например: `2-294731-...`)
- Попробуйте получить новый токен

### Токен быстро истекает
- Возможно у SoundCloud изменилась политика
- Используйте режим без токена (публичный API)
- Получайте новый токен по необходимости

### Ошибки API даже с токеном
- Проверьте что вы авторизованы на SoundCloud
- Токен может быть отозван
- Получите свежий токен
