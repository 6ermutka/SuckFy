# Исправление фонового воспроизведения треков

## Проблема
При сворачивании приложения или блокировке экрана треки переставали автоматически переключаться на следующий.

## Решение
Создан нативный модуль `AudioPlayerModule` для Android, который:
1. **Использует Android MediaPlayer** вместо react-native-sound для надёжного фонового воспроизведения
2. **Отправляет событие `onTrackCompleted`** в JavaScript, когда трек заканчивается
3. **Использует WAKE_LOCK** для предотвращения засыпания процессора во время воспроизведения
4. **Работает в фоновом режиме** даже когда приложение свёрнуто

## Что было изменено

### Нативные модули (Android)
1. **`AudioPlayerModule.kt`** - новый модуль для управления воспроизведением:
   - MediaPlayer с поддержкой фонового режима
   - Wake Lock для предотвращения засыпания
   - События: `onTrackLoaded`, `onTrackCompleted`, `onTrackError`

2. **`AudioPlayerPackage.kt`** - регистрация модуля

3. **`MainApplication.kt`** - добавлен `AudioPlayerPackage()`

4. **`AndroidManifest.xml`** - добавлены разрешения:
   - `WAKE_LOCK`
   - `FOREGROUND_SERVICE`

### JavaScript сервисы
1. **`src/services/AudioPlayerService.ts`** - обёртка для нативного модуля:
   - Управление воспроизведением
   - Подписка на события завершения трека
   - Автоматическое управление wake lock

### Контекст плеера
2. **`src/contexts/PlayerContext.tsx`** - обновлён для использования нового сервиса:
   - Использует `AudioPlayerService` на Android
   - Сохранена совместимость с iOS (react-native-sound)
   - Добавлена функция `handleTrackCompletion()` для автоматического переключения треков
   - Подписка на событие `onTrackCompleted` из нативного модуля

## Как это работает

### В активном режиме
- Приложение открыто, треки воспроизводятся и переключаются как обычно

### В фоновом режиме
1. Пользователь сворачивает приложение или блокирует экран
2. **Wake Lock** не даёт процессору полностью заснуть
3. **MediaPlayer** продолжает воспроизведение в фоне
4. При завершении трека **MediaPlayer** отправляет событие `onTrackCompleted`
5. JavaScript получает событие через **DeviceEventEmitter**
6. **PlayerContext** вызывает `handleTrackCompletion()`
7. Автоматически загружается и воспроизводится следующий трек в очереди

## Тестирование

1. Запустите приложение на Android устройстве
2. Начните воспроизведение плейлиста с несколькими треками
3. Сверните приложение или заблокируйте экран
4. Треки должны автоматически переключаться в фоне
5. Проверьте уведомление - оно должно обновляться при смене треков

## Совместимость

## Примечания

- Wake Lock автоматически освобождается при паузе или остановке
- Wake Lock ограничен 10 минутами на один трек для экономии батареи
- При повторном запуске воспроизведения wake lock активируется снова
